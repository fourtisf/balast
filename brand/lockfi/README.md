# LockFi brand files

The pin arch: a padlock's shackle and its tumbler pins drawn as one bar chart.
One colour only. The geometry lives in `components/shell/Logo.tsx`; these files
are written from it by `npm run brand:lockfi`.

| File | Use |
|---|---|
| `mark-white.svg`, `mark-black.svg`, `mark-currentcolor.svg` | The mark alone |
| `icon-black*.svg/png` | The primary icon: favicon, X avatar, app icon (white mark on the premium black tile) |
| `icon-dark*.svg/png` | White mark on the site's black |
| `icon-dark-square*` | Full-bleed, for platforms that round the corners themselves |
| `icon-light*`, `icon-white-tile.svg` | On light grounds |
| `lockup-*.png` | Mark and wordmark |
| `og-card.png` | Link preview, also served as `/og-card.png` |
